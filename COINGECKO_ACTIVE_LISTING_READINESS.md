## Active Listing status

**Status: NOT READY TO SUBMIT as an Active Listing.**

CoinGecko's published prerequisite is that the asset must be actively tradable on at least one exchange tracked by CoinGecko. A testnet deployment, a token contract alone, or a self-created pool on an unsupported venue does not satisfy this prerequisite.

## Work required before an Active Listing application

1. **Production deployment**
   - Decide and document the production network.
   - Review and test the production contract.
   - Deploy the production token to the selected mainnet.
   - Verify the exact source code on the relevant mainnet block explorer.
   - Publish the production contract address, chain, decimals, total supply and holder/distribution information.
   - Keep the existing Polygon Amoy contract clearly labelled as testnet; do not silently replace or misrepresent it.

2. **Official project presence**
   - Publish a project-owned, working website with the token purpose, project description, team/contact details, tokenomics, risks, contract address, network, explorer, and official social links.
   - Publish a whitepaper or technical paper consistent with the deployed contract.
   - Publish a high-resolution token logo and consistent project identity.
   - Ensure all public links work and agree with each other.

3. **Transparent tokenomics**
   - Disclose total supply and circulating supply separately.
   - Explain allocations, vesting, locked balances, treasury/team holdings and any liquidity allocation.
   - Do not claim a circulating supply or market capitalization without verifiable evidence.

4. **Real, supported trading market**
   - Select a legitimate exchange/DEX market that CoinGecko already tracks.
   - Confirm the production token is supported by that market and the correct chain.
   - Establish genuine liquidity and organic trading; do not fabricate volume, wash-trade, or imply guaranteed price/returns.
   - Record the exact market/pair URL and verify live trades and liquidity.
   - Check the venue against CoinGecko's supported Exchanges list before applying.

5. **Ownership verification**
   - Link the official social account from the official project website.
   - Publish a public verification post from that official account stating that GASTROCOIN is submitting an Active Listing request.
   - Include the GeckoTerminal URL if the production market is indexed there.
   - Save the public post URL.
   - After CoinGecko issues a request ID, reply to the original post with that exact ID.

6. **CoinGecko application**
   - Sign in to CoinGecko's Partners Platform.
   - Open Request & Listing → New Request → New Coin/Token Listing → Active Listing.
   - Complete every required field using production/mainnet details and real market data.
   - Attach the logo and provide the website, whitepaper, explorer, official social links, market/pair URL, circulating-supply explanation and public verification post.
   - Submit once, save the confirmation email and request ID, and monitor the application in the dashboard.
