# PRESENTACIÓN INSTITUCIONAL

## GASTROCOIN

GASTROCOIN es un proyecto de ecosistema digital
que busca conectar gastronomía e innovación blockchain.

### Dirección
Fundador y director: Ricardo Rodríguez.

### Visión
Desarrollar una iniciativa digital transparente,
con identidad propia, documentación técnica
y oportunidades de integración con el sector gastronómico.

### Misión
Construir una comunidad alrededor de la innovación
gastronómica y tecnológica.

### Principios
- Transparencia.
- Seguridad.
- Documentación verificable.
- Responsabilidad.
- Desarrollo progresivo.

Este documento no constituye una oferta de inversión
ni una promesa de rentabilidad.
