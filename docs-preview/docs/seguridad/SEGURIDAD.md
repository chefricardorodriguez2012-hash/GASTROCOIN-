# POLÍTICA DE SEGURIDAD

1. Nunca publicar frases semilla.
2. Nunca publicar claves privadas.
3. Nunca subir archivos .env.
4. Verificar contratos antes de anunciar direcciones.
5. Verificar la red blockchain.
6. Conservar copias de seguridad.
7. Revisar permisos administrativos.
8. No anunciar auditorías inexistentes.
9. No prometer rentabilidad.
10. Registrar cambios importantes.

Las claves privadas y credenciales deben permanecer
fuera de este repositorio.
